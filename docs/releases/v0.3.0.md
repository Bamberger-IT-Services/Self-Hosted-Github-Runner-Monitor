## Update
Info › Updates › „Jetzt auf 0.3.0 aktualisieren“ (vorher „Jetzt prüfen“) oder auf der VM:
`sudo /opt/runner-monitor/aktuell/einrichten.sh aktualisieren`.

## Einmalig nach dem Update
Keine einmaligen Schritte. Die neuen Angaben der Einrichtung (lokales Netz, Runner-Dienst aktiv)
schreibt das Skript beim nächsten `sudo /opt/runner-monitor/aktuell/einrichten.sh`; ohne sie
zeigt der Monitor nur weniger Einzelheiten.
