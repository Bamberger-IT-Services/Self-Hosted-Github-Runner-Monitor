# Version 0.7.0

**Stand: 25.10.2026 · veröffentlicht am 25.10.2026**

Zuverlässiges Nacht-Update, Änderungen vor dem Update im Blick und die Oberfläche auf Englisch.
Handbuch dieser Version:
`https://github.com/Bamberger-IT-Services/Self-Hosted-Github-Runner-Monitor/tree/v0.7.0/docs/handbuch`

## Update
Info › Updates: erst „Jetzt prüfen“, dann „Jetzt auf 0.7.0 aktualisieren“ – oder auf der VM:
`sudo /opt/runner-monitor/aktuell/einrichten.sh aktualisieren`. Mit „Automatisch aktualisieren“
spielt der Monitor es nachts selbst ein.

## Einmalig nach dem Update
Keine Schritte nötig. Offene Dashboard-Fenster einmal neu laden, damit die neue Oberfläche (Sprache) geladen wird.

## Was ist neu
- Nacht-Update wartet, bis der Runner frei ist: ab 3 Uhr vorgemerkt, gestartet, sobald kein Job läuft (bis 7 Uhr), höchstens ein Versuch je Nacht
- Info › Updates zeigt alle Änderungen seit der installierten Version, einmalige Schritte hervorgehoben
- Oberfläche auf Englisch umschaltbar: Dashboard (Info › Darstellung › Sprache), Anmeldung und Einrichtung; Vorgabe nach Browser
- `SECURITY.md`: Sicherheitslücken vertraulich über GitHub melden

## Bekannt
- Release-Notizen und Handbuch bleiben deutsch. Kein HTTPS ohne Proxy, keine 2FA, ein Runner je VM.
