## Einmalige Schritte
- War die alte Terminalansicht (`monitor-einrichten.sh`, ttyd, Port 7681) installiert: Das
  Einrichtungsskript ersetzt sie und übernimmt das Token. Danach kann `/etc/runner-monitor.env`
  gelöscht und die Firewall-Regel für Port 7681 entfernt werden.

## Kernabläufe zum Durchklicken
1. `sudo ./einrichten.sh` → Code → Zugang → GitHub prüfen und speichern → Anmeldung.
2. Dashboard füllt sich; einen Workflow starten → „Job läuft“, Schritte, Live-Log.
3. Runner-Dienst stoppen (`sudo systemctl stop 'actions.runner.*'`) → rote Meldung, „Was tun?“; wieder starten.
4. Info › Darstellung umschalten, Abmelden, erneut anmelden.

## Bekannte Grenzen
- Kein HTTPS (LAN), keine 2FA, ein Runner je VM, Docker-Ansicht folgt später.
- GitHub-Kontingent reicht im 30-s-Takt für etwa 35 Repositories (A-07).
