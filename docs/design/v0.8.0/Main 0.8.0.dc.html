Über diesen Monitor

Live-Dashboard für selbst gehostete CI-Runner auf einer VM – GitHub Actions, Forgejo, Gitea, GitLab, andere mit Grundüberwachung: Runner-Status, Auslastung mit Netzwerk, Prozesse, Platten, Jobs je Repository und Live-Log. Fehler und Hinweise erscheinen als Meldung in der Mitte der Kopfzeile, „Was tun?“ führt zur passenden Anleitung.
