GitHub anbindenoptional

Mit einem nur lesenden Token zeigt der Monitor, welche Workflows je Repository laufen und warten, und ob GitHub den Runner sieht. Ohne Token funktioniert alles andere trotzdem.

Aus der Runner-Konfiguration erkannt.
{{e.text}}
So erstellen Sie das Token
  1. Auf GitHub ein „Fine-grained token“ anlegen (Link unten).
  2. Resource owner: die Organisation. Repository access: All repositories.
  3. Repository-Rechte: Actions und Metadata jeweils „Read-only“.
  4. Organisations-Recht: Self-hosted runners „Read-only“, damit der Online-Status angezeigt wird.
  5. Ablauf z. B. 90 Tage. Der Monitor warnt 14 Tage vorher.
  6. Token kopieren und links einfügen.
Token-Seite auf GitHub öffnen ↗

Später auf der VM nachholen: sudo /opt/runner-monitor/aktuell/einrichten.sh token
