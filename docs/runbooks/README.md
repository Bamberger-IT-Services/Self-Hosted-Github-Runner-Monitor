# Runbooks

**Stand: 24.10.2026 · Version 0.6.0**

Schritt-für-Schritt-Anleitungen für Störungen (Anweisung 07). Kurzfassungen stehen auch im
Monitor unter Info › „Was tun, wenn …“.

| Runbook | Wann |
|---|---|
| [runner-dienst-gestoppt](runner-dienst-gestoppt.md) | Meldung „Runner-Dienst gestoppt“ oder „Runner offline bei GitHub“ |
| [platte-voll](platte-voll.md) | Meldung „Platte knapp“, Jobs scheitern mit „No space left on device“ |
| [monitor-startet-nicht](monitor-startet-nicht.md) | Seite nicht erreichbar, „Getrennt“ bleibt stehen |
| [update-fehlgeschlagen](update-fehlgeschlagen.md) | Meldung „Update fehlgeschlagen“ oder Monitor nach Update kaputt (Rückfall) |
| [zugang-gesperrt](zugang-gesperrt.md) | Passwort vergessen, Anmeldung gesperrt |
| [github-nicht-erreichbar](github-nicht-erreichbar.md) | Workflows zeigen alten Stand, Token ungültig oder abgelaufen |
| [live-log-leer](live-log-leer.md) | Job läuft, aber das Live-Log zeigt keine neuen Zeilen |

Zeichnet sich eine Störung ab, die länger dauert: Bericht nach
[Vorlage](https://github.com/Bamberger-IT-Services/Public/blob/main/anweisungen/vorlagen/stoerungsbericht.md)
in `docs/stoerungen/` – ohne echte Adressen und Namen.
